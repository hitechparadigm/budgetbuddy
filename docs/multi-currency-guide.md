# Multi-Currency Support Guide

**Last Updated**: 2026-01-31
**Version**: 1.0

## Overview

BudgetBuddy supports 6 major currencies, allowing users worldwide to manage their budgets in their local currency. This guide explains how to select, change, and use different currencies in BudgetBuddy.

## Supported Currencies

| Currency          | Code | Symbol | Countries                                       |
| ----------------- | ---- | ------ | ----------------------------------------------- |
| US Dollar         | USD  | $      | United States, Ecuador, El Salvador, and others |
| Euro              | EUR  | €      | European Union countries                        |
| British Pound     | GBP  | £      | United Kingdom                                  |
| Canadian Dollar   | CAD  | C$     | Canada                                          |
| Australian Dollar | AUD  | A$     | Australia                                       |
| Japanese Yen      | JPY  | ¥      | Japan                                           |

## Selecting Your Currency

### During Onboarding

When you first sign up for BudgetBuddy, you'll be asked to select your preferred currency:

1. **Complete Registration**: Enter your email and password
2. **Select Location**: Choose your city or country
3. **Choose Currency**: Select from the list of supported currencies
4. **Set Family Size**: Enter your household size
5. **Generate Budget**: AI will create a budget in your selected currency

**Default Currency**: If you skip currency selection, USD will be used by default.

### After Onboarding

You can change your currency preference at any time in Settings:

1. Open **Settings** from the menu
2. Navigate to **Currency Settings**
3. View your current currency
4. Select a new currency from the dropdown
5. Read the warning message carefully
6. Confirm the change

Each currency is formatted according to its local conventions:

- **Format**: $1,234.56
- **Decimal Places**: 2
- **Thousands Separator**: Comma (,)
- **Decimal Separator**: Period (.)

## Changing Your Currency

### Important Warning

⚠️ **Before changing your currency, please understand:**

- **Existing budgets will NOT be converted** - They will keep their original currency
- **Existing transactions will NOT be converted** - They will keep their original currency
- **Only new budgets** will use the new currency
- **Only new transactions** will use the new currency

### Step-by-Step Guide

1. **Open Settings**
   - Click the menu icon (☰)
   - Select "Settings"

2. **Navigate to Currency Settings**
   - Scroll to the "Currency" section
   - View your current currency

3. **Select New Currency**
   - Click the currency dropdown
   - Choose your new currency from the list

4. **Review Warning**
   - Read the warning message carefully
   - Understand that existing data won't be converted

5. **Confirm Change**
   - Click "Update Currency"
   - Your currency preference is now updated

6. **Verify Change**
   - Check that the new currency is displayed
   - Create a new budget to see the new currency in action

### What Happens After Changing Currency

**Immediately**:

- Your profile currency is updated
- The UI displays the new currency symbol
- New budgets will use the new currency

**Existing Data**:

- Old budgets remain in their original currency
- Old transactions remain in their original currency
- You can still view and edit old data

**New Data**:

- New budgets use the new currency
- New transactions use the budget's currency
- All amounts are formatted in the new currency

## Using Multiple Currencies

### Scenario: Moving to a New Country

If you move from the US to the UK:

1. **Before Moving**:
   - Your budgets are in USD
   - Your transactions are in USD

2. **Change Currency**:
   - Update your currency to GBP in Settings
   - Confirm the change

3. **After Moving**:
   - Old budgets remain in USD (for historical records)
   - Create new budgets in GBP
   - New transactions are in GBP

### Scenario: Traveling

If you're traveling temporarily:

**Option 1: Keep Your Home Currency**

- Don't change your currency setting
- Enter transactions in your home currency
- Convert amounts manually if needed

**Option 2: Switch Temporarily**

- Change to the local currency
- Create a travel budget
- Change back when you return home

## Frequently Asked Questions

### Can I convert my existing budgets to a new currency?

No, automatic currency conversion is not currently supported. Existing budgets will keep their original currency. You can create new budgets in the new currency.

### Can I have budgets in different currencies?

Yes, you can have budgets in different currencies, but each individual budget can only use one currency. For example, you might have:

- January 2026 budget in USD
- February 2026 budget in EUR (after changing currency)

### What if I enter a transaction in the wrong currency?

You can delete the transaction and create a new one with the correct currency. Make sure to select the right budget (which has the correct currency).

### Can I use multiple currencies in one budget?

No, each budget can only use one currency. All categories and transactions within a budget must use the same currency.

### Will currency conversion be added in the future?

Yes! Currency conversion with real-time exchange rates is planned for Phase 2. This will allow:

- Automatic currency conversion
- Multi-currency budgets
- Historical exchange rate tracking

### How do I know which currency a budget uses?

The currency code (USD, EUR, etc.) is displayed in the budget header. All amounts in that budget are in that currency.

### Can I change a budget's currency after creation?

No, once a budget is created, its currency cannot be changed. You would need to create a new budget with the desired currency.

## Best Practices

### For New Users

1. **Choose Carefully**: Select your currency during onboarding
2. **Match Your Location**: Use the currency of your primary country
3. **Stay Consistent**: Avoid changing currency frequently

### For Existing Users

1. **Plan Ahead**: Only change currency if you're permanently moving
2. **Finish Current Month**: Complete the current month's budget before changing
3. **Start Fresh**: Create new budgets after changing currency
4. **Keep Records**: Old budgets remain accessible for historical reference

### For International Users

1. **Primary Currency**: Use the currency where you spend most of your money
2. **Travel Budgets**: Create separate budgets for travel in different currencies
3. **Manual Conversion**: Convert amounts manually if needed
4. **Wait for Phase 2**: Currency conversion features are coming soon

## Troubleshooting

### Currency Not Displaying Correctly

**Problem**: Currency symbol or format looks wrong

**Solution**:

1. Check your browser/app language settings
2. Ensure you selected the correct currency
3. Refresh the page/app
4. Contact support if issue persists

### Can't Change Currency

**Problem**: Currency dropdown is disabled

**Solution**:

1. Ensure you're logged in
2. Check your internet connection
3. Try logging out and back in
4. Contact support if issue persists

### Wrong Currency in Budget

**Problem**: Budget shows wrong currency

**Solution**:

1. Check when the budget was created
2. Budgets created before currency change keep old currency
3. Create a new budget to use the new currency
4. Delete and recreate if needed
