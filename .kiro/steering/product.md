# BudgetBuddy Product Context

## Vision

AI-powered family budgeting app (EveryDollar-inspired). Web + iOS + Android. Freemium model.

## Users

- Individual: simple budgeting, AI suggestions
- Family: primary + spouse/partner, role-based permissions, shared finances
- Premium ($9.99/mo): ad-free, advanced reporting, data export

## Core Value

1. Budget Setup: AI-powered generation using location + family size (348 cities)
2. Transaction Tracking: quick entry, real-time progress, <200ms
3. Family Collaboration: secure sharing, RBAC, real-time sync
4. Data Reliability: no data loss, offline mobile, automatic sync

## Performance Targets

- API p95 <500ms, page load <2s, 99.9% availability
- Year 1: 10K users, 5% premium conversion

## Out of Scope (Future)

Bank integration (Plaid Phase 2), investment tracking, bill pay, multi-currency advanced, social features
